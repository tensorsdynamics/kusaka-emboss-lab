# Разработка

## Стек

- React 19;
- TypeScript;
- Vite;
- Three.js;
- fflate для детерминированной упаковки 3MF;
- Sharp для детерминированной генерации эталонных моделей;
- встроенный `node:test`.

## Структура

```text
src/
  KusakaLab.tsx          интерфейс и Three.js-сцена
  image-processing.js    Levels, Threshold, Blur и яркость
  model-core.js          замкнутая печатная геометрия
  three-mf-exporter.js   3MF Core + назначения Bambu extruder 1/2
scripts/
  generate-models.mjs    эталонные 3MF/STL/OBJ
tests/
  model.test.mjs         геометрия и обработка изображения
  project.test.mjs       production-сборка и состав проекта
public/
  models/                исходная демонстрационная маска
```

## Пайплайн

1. Картинка уменьшается до сетки `384 × 384`.
2. RGBA переводится в яркость.
3. Применяются Levels, Gamma, Threshold, мягкость и Blur.
4. Контур интерполируется между сэмплами, поэтому край не привязан к квадратам
   исходной сетки.
5. Для объединённых STL/OBJ рельеф замыкается вниз с небольшим пересечением
   основы.
6. Three.js показывает модель и экспортирует STL/OBJ.
7. 3MF-экспорт убирает пересечение на границе материалов, объединяет все
   relief-меши в отдельную часть и добавляет стандартные base materials вместе
   с Bambu-метаданными частей F1/F2.
8. fflate упаковывает XML в детерминированный 3MF-архив.

## Локальная разработка

```bash
npm ci
npm run dev
```

## Обязательная проверка

```bash
npm test
```

Тесты проверяют размеры, замкнутость оболочек, отсутствие копланарного фона,
субпиксельные вершины контура, Levels, production-сборку, структуру 3MF,
назначения `extruder 1/2` и выходные модели.

## Правила изменений

- Не добавляй серверную загрузку изображений без отдельного обоснования.
- Не допускай совпадения пустого heightfield с верхом основы: это возвращает
  z-fighting.
- Любое изменение сетки или контура сопровождай тестом замкнутости.
- Не коммить сгенерированные 3MF/STL/OBJ: они воспроизводятся через
  `npm run models`.
- Пользовательский интерфейс и документацию веди на русском языке.
