# История изменений

## 1.0.0 — 2026-07-28

- загрузка PNG, JPG и WebP;
- Levels, Gamma, Threshold, мягкость, Blur и смена полярности;
- параметрическая круглая основа и борт;
- сетка `384 × 384` с субпиксельным контуром;
- замкнутая геометрия без копланарного фона;
- экспорт STL и OBJ;
- статическая сборка, Docker и автоматизация GitHub Pages;
- русская документация.
